# Parity (working name)

Detects personalized ("surveillance") pricing and shows a shopper the lowest offer anyone in the network was actually shown for the same item at the same retailer.

This repo was cleared on 2026-09-22 to become Parity's monorepo. The previous contents (Aivre, an appraisal workspace) are preserved at git tag `aivre-v1-final`.

Nothing is built yet. Start here:

- `docs/BRIEF.md`: the founder's master build brief.
- `docs/PLAN.md`: the plan, assumptions, and the open questions that gate Phase 0.
- `docs/DECISIONS_NEEDED.md`: the running list of founder decisions.
