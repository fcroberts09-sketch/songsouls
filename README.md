# Parity (working name)

Detects personalized ("surveillance") pricing and shows a shopper the lowest offer anyone in the network was actually shown for the same item at the same retailer.

This repo was cleared on 2026-09-22 to become Parity's monorepo. The previous contents (Aivre, an appraisal workspace) are preserved in git history at commit `843be1a` on `main` (run `git tag aivre-v1-final 843be1a && git push origin aivre-v1-final` from your machine to make it easy to find; this session is not allowed to push tags).
